Plane Radar

Live ADS-B radar for the ESP32-C3 Super Mini. Flash it from your browser over Web Serial.

Web Serial isn't available in this browser. Use Chrome or Edge on desktop. This page must be served over HTTPS to flash. Recommended. Updates the app and keeps your WiFi & settings. For a board already running Plane Radar.
Erases everything, including WiFi & settings. For a new board or a full reset.

How to install

1. Plug the board in with a data USB-C cable (not charge-only)
2. Pick a version above (defaults to the latest)
3. Click a button, then Connect and choose the board's serial port
Works in Chrome and Edge on desktop only (Web Serial). Not supported on Firefox, Safari, or mobile.
