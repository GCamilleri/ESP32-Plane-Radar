Plane Radar

Live ADS-B radar for the ESP32-C3 Super Mini. Flash it from your browser over Web Serial.

Web Serial isn't available in this browser. Use Chrome or Edge on desktop. This page must be served over HTTPS to flash.

How to install

1. Plug the board in with a data USB-C cable (not charge-only)
2. Click Connect and pick the board's serial port
3. Choose:
  • Install: fresh setup (erases everything)
  • Keep settings: update and preserve your WiFi & preferences
Works in Chrome and Edge on desktop only (Web Serial). Not supported on Firefox, Safari, or mobile.

Prefer the command line? See the README for esptool instructions · Releases · Source
